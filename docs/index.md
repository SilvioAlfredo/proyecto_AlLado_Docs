# 🤝 Proyecto AlLado - Documentación Oficial

Bienvenido a la documentación técnica y funcional del proyecto **AlLado**, la plataforma digital diseñada para conectar trabajadores y empleadores en el ámbito comunitario a través de un modelo de *Postulación Inversa*.

## 💡 ¿Cómo colaborar con la documentación?

Para sugerir cambios o agregar nuevos requerimientos a la plataforma, por favor consulta con el equipo de desarrollo o abre una solicitud de cambio (*Pull Request*) sobre los archivos `.md` de la carpeta `docs/`.
